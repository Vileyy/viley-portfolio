# Viley's Professional Portfolio 🚀

A modern, high-performance personal portfolio website showcasing enterprise client systems, front-end architecture, professional experience, and technical projects.

Live Demo: [viley.dev](https://doanquochieuu.vercel.app/)

---

## 🎨 Design & Aesthetic Highlights
* **Enterprise & Client Focused**: Separates commercial client systems from personal showcases with dedicated interactive preview mockups and deep-dive technical specs.
* **Modern Alternating Layout**: Projects are displayed in a clean, split-row grid (alternating details and interactive mockups) for an agency-grade experience.
* **Interactive UI Mockups**: Built custom in-code dashboard simulations for enterprise platforms (Orbit's Berlin-timezone schedule simulation & route polylines, Atlas's Kanban & Konva blueprint markup).
* **Premium Micro-Animations**: Powered by **Framer Motion** for smooth scroll entries, tabs, interactive modals, and floating badges.
* **Official Brand Icons**: All technology badges styled with official brand logos from `react-icons` and `lucide-react`.

## 💻 Featured Projects & Client Engagements

### 🏢 1. O.R.B.I.T — Sales Schedule Simulation & Operations (Client Project)
A large-scale B2B sales management and schedule simulation platform engineered for the German market.
* **Client**: Galvanek GmbH (Germany) via AutoMate Solutions
* **Role**: Frontend Developer (Owner of Schedule Simulation Module)
* **Tech Stack**: React 18, TypeScript, Vite, Recharts, Leaflet, Pusher WebSockets, FullCalendar, TanStack Query, Playwright, Bun test.
* **Key Achievements**:
  * Owned and developed the Schedule Simulation engine with multi-iteration snapshot caching.
  * Built a precision week-based calendar (Europe/Berlin timezone) with 100% collision prevention.
  * Integrated Leaflet map polylines for live route visualization and Recharts for KPI analytics.

### 🏗️ 2. Galvanek Atlas (Montago Web) — Construction ERP (Client Project)
A comprehensive enterprise ERP platform custom-built for large-scale German construction operations.
* **Client**: Galvanek-Bau (Germany) via AutoMate Solutions
* **Role**: Frontend Developer
* **Tech Stack**: React 18, TypeScript, Ant Design 5, Leaflet, Konva (Canvas Annotation), DHTMLX Gantt, @dnd-kit, Pusher, JWT / RBAC.
* **Key Achievements**:
  * Implemented multi-role RBAC architecture (Admin, PM, Site Owner, Subcontractor) with JWT token rotation.
  * Built interactive Kanban boards (@dnd-kit) and Gantt timelines for construction milestone tracking.
  * Developed architectural blueprint defect markup using Konva canvas for paperless inspection protocols.
  * Integrated geospatial map with Germany's 5-digit postcode (PLZ) database for subcontractor radius assignment.

## 🚀 Getting Started (Local Development)

```bash
# Clone the repository
git clone https://github.com/Vileyy/portfolio-viley.git
cd portfolio-viley

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
